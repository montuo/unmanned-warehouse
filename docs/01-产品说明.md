# 产品说明

无人仓系统给已经在开仓、或准备帮别人开无人仓的技术团队做商业授权。

## 适合谁

- 有开发能力，不想从零对接美团、淘宝闪购、京东秒送的团队
- 已经有几座即时零售仓，订单和库存散在多个工具里的连锁
- 做仓店信息化，需要一套能交付的成套系统，而不是只买一个收银插件

## 不适合谁

希望克隆本仓库就在本地跑起后台的人。这个仓库没有源码。

## 仓里实际在用的闭环

1. 顾客在美团闪购、淘宝闪购或京东秒送下单，订单进入同一座仓。
2. 仓务人员在小程序或 App 里按货位拣货。缺货走平台侧的整单逆向。
3. 库存随履约扣减。货位上没货时，从别的仓调拨补进来。
4. 骑手到仓核验后开门取货。顾客也可以扫码看在售商品，选择到店取货或由仓配送出去。
5. 总部看今日的单、缺货和空货位，决定补哪一座仓。
