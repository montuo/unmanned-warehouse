# 授权与交付

## 卖的是什么

一套可以部署到购买方自己环境里的无人仓系统，加上把第一座仓跑通的实施，以及上线后的年度维护。

不卖公开仓库里的阅读权。阅读是免费的，使用权要签合同。

## 交付里通常有

- 购买方独立环境中的后台
- 仓务微信小程序、仓务 App、骑手小程序
- 第一座仓的实施：仓库档案、商品、库存货位、平台店铺对接、开门设备联调
- 约定范围内的年度维护（平台接口变化、故障处理、新仓开通方式）

界面上的品牌名可以换成购买方的名字。引力光年的品牌、供货和加盟政策不随系统授权一并给到。

## 购买方自己准备

- 营业主体，以及美团、淘宝闪购（饿了么）、京东秒送的商家账号和开发者资质
- 服务器和域名
- 仓库里的门锁、监控、打印设备，以及现场安装
- 自己的商品资料和仓务人员

没有平台资质，订单进不了仓。没有门锁和监控，无人值守只完成了一半。

## 报价方式

按项目谈两笔：实施费，以及每年的维护费。第一座仓用来把链路跑通，新仓如何开通写在合同里。

本仓库不标价格。电话里说清楚城市、仓数、已有哪些平台店铺，再约一次看系统。

## 评估时建议问的六个问题

1. 三套平台的订单是否进同一个订单池，仓务人员要不要换三个 App。
2. 拣货时能不能看到货位，缺货怎么回平台。
3. 库存扣减和调拨之后，货位是否还对得上实物。
4. 骑手到仓开门和远程开门是否在同一套权限里。
5. 顾客扫码到店买，和平台订单是不是进同一套库存。
6. 平台开发者账号是谁的，停付维护费之后系统和数据怎么处理。
