# 无人仓系统

商业授权的产品介绍。这个仓库给开发者和准备自建系统的团队看。

**这里没有业务源码，也不能把本仓库当成可以运行的后台。**

用浏览器打开演示页：[demo/index.html](demo/index.html)

## 它解决什么

无人仓要同时接美团闪购、淘宝闪购（饿了么）、京东秒送。订单、货位、拣货、调拨、远程开门如果拆在好几套工具里，仓里的人对不上库存，缺货也不知道该从哪一仓补。

无人仓系统把这些收成一套：平台订单进同一座仓，按货位拣货，卖完扣库存，缺了做调拨。骑手到店开门取货，顾客也可以扫码到店买。管理后台管商品、仓库和渠道，总部看今天的单、缺货和空货位。

这套系统已经在自有无人仓使用。

## 这个仓库里没有什么

- 后端、管理后台、小程序、App 的源码
- 数据库脚本、部署配置、接口密钥
- 可登录的演示账号
- 仓库经营数据

源码按商业合同单独交付，不通过公开仓库分发。

## 购买后通常交付

- 独立部署的后台
- 仓务端（微信小程序与 App）、骑手取货端
- 一座仓的实施：建仓、商品、货位、平台店铺对接、开门
- 上线后的年度维护

平台商家资质、服务器、门锁和监控由购买方自己持有。细则见 [docs/03-授权与交付.md](docs/03-授权与交付.md)。
